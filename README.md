# Portfólio — Daniel Medeiros

Portfólio profissional de **Daniel Medeiros**, Product Builder e Full-Stack Developer.

O site apresenta projetos reais levados da ideia à produção, combinando engenharia de software, experiência do usuário e visão de produto. A seleção inclui um site institucional e a evolução do FIND para o ONEFIND, uma plataforma SaaS multi-tenant de agendamento.

## Conteúdo

- Projetos e cases selecionados
- Processo de evolução profissional
- Competências em produto e engenharia
- Stack técnica
- Apresentação e canais de contato

## Projetos em destaque

### Jaque Medeiros

Site institucional com conteúdo estruturado, experiência responsiva, integrações de canais oficiais e fundamentos de SEO técnico.

[Visitar projeto](https://www.jaquemedeirospt.com.br)

### ONEFIND

SaaS multi-tenant de agendamento e gestão para negócios de serviços, com reservas, painel administrativo, autenticação, isolamento de dados e assinaturas.

[Visitar produto](https://www.onefind.com.br)

## Estrutura

Este portfólio é uma página estática e autocontida:

```text
index.html   # conteúdo, estilos e estrutura da página
favicon.png  # identidade visual do site
```

## Executar localmente

Abra o arquivo `index.html` no navegador ou use qualquer servidor HTTP local.

## Objetivo

Este repositório representa a trajetória profissional de Daniel como um todo. O ONEFIND é um dos principais projetos, mas a identidade do portfólio permanece centrada na capacidade de construir diferentes produtos digitais de ponta a ponta.
